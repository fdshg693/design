# URL 短縮サービス

長い URL を `https://sho.rt/aZ3k9Qx` のような短い URL に変換し、アクセスされたら元の URL へリダイレクトする。

## 前提

- 機能要件
    - 長い URL を登録すると短縮 URL を返す
    - 短縮 URL にアクセスすると元の URL へリダイレクトする
    - 有効期限(任意、デフォルトなし)
    - クリック数の集計(リアルタイム性は不要、数分遅れで良い)
- 非機能要件
    - リダイレクトは p99 50ms 以内
    - リダイレクトの可用性 99.99%(作成側は 99.9% で良い)
    - 短縮 URL は推測されにくい必要は**ない**(公開リンク前提)
- 規模
    - 新規作成: 平均 10 件/秒(≒ 86 万件/日)
    - リダイレクト: 平均 1,000 件/秒、ピーク 5,000 件/秒(読み:書き ≒ 100:1 と仮定)
    - 保存件数: 10 件/秒 × 3,150 万秒/年 × 5 年 ≒ **16 億件**
    - ストレージ: 1 件 500B と仮定して 16 億 × 500B ≒ **800GB**

## スコープ外

- ユーザー認証・管理画面: 主題(ID 生成とリダイレクト)から外れるため
- 不正 URL(フィッシング)の検査: 別トピックとして扱う
- マルチリージョン: まずは単一リージョンで考える
